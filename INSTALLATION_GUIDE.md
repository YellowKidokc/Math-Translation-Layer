
## 🚀 Next Steps

### 1. Enable the Plugin
1. Open Obsidian
2. Go to **Settings** → **Community Plugins**
3. Find **"Theophysics Math Translator"** in the list
4. Toggle it **ON**

### 2. Configure Settings
1. Go to **Settings** → **Theophysics Math Translator**
2. Verify the scan folders are set to: `_Term_Pages, data analytic, complete logos final papers` (default)
3. Verify the AA Hub path is `data analytic/AA Math Translation Hub.md`
4. You can add or remove folders by editing the comma-separated list

### 3. Build Your AA Math Translation Hub

#### Option A: Quick Start
1. Open **Command Palette** (Ctrl/Cmd + P)
2. Type: **"Scan All Folders for Math"**
3. Wait for scan to complete (scans _Term_Pages, data analytic, and complete logos final papers)
4. Click **"Build AA Math Translation Hub"**
5. Your hub will be created at `data analytic/AA Math Translation Hub.md`

#### Option B: Step by Step
1. Make sure you have these folders in your vault:
   - `_Term_Pages`
   - `data analytic`
   - `complete logos final papers`
2. Add some notes with LaTeX equations to those folders
3. Run the scan command (scans ALL configured folders)
4. Build the hub in data analytic folder

### 4. Use Quick Translation (Works Anywhere!)
1. Open **any note** in your vault
2. **Highlight** any LaTeX equation (e.g., `$E = mc^2$`)
3. **Right-click** → **"Translate to Narrative"**
4. See the translation in a modal window
5. Copy to clipboard if needed

## 🔧 Troubleshooting

### Plugin Not Showing Up?
- Make sure you enabled it in Settings → Community Plugins
- Try reloading Obsidian (Ctrl/Cmd + R)

### Scan Not Finding Equations?
- Check that your scan folders are correct (comma-separated list)
- Make sure you have LaTeX equations in `$...$` or `$$...$$` format
- Verify the folders exist in your vault (_Term_Pages, data analytic, complete logos final papers)
- Plugin will skip folders that don't exist and show a warning

### Hub Not Creating?
- Check the AA Hub path in settings
- Make sure the `data analytic` folder exists (hub is always created there)
- Try running the scan first before building the hub
- Check if at least one of the scan folders exists and has equations
